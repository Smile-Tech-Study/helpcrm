В каждой образовательной организации есть бланки документов, которые заполняет слушатель, желающий пройти обучение. \
Во Flow есть возможность загрузить бланки вашей организации, предварительно подставив в них значение ключевых слов.

:::info

Прежде чем приступить к работе с шаблонами заполните подписантов и префикс на странице организации.

:::

**Шаблоны** - это бланки документов, которые **автоматически** заполняются данными организации, [слушателя](./../../slushateli/_index.md), данных о [программе](./../../obuchenie/_index.md) и [потоках](./../../obuchenie/Potok/_index.md), а также [подписантов](./../podpisanty.md) и префикса организации на основание[ ключевых слов](./klyuchevye-slova.md).\
В организации может быть создано несколько пакетов документов. \
**Пакет документов** - это набор из нескольких шаблонов документов. При добавлении организации по умолчанию создается первый пакет документов.

Во Flow есть возможность добавить несколько пакетов документов, затем выбирать необходимый пакет в [заявке](./../../slushateli/zayavki/sposoby-sozdaniya-zayavok/_index.md) слушателя.
